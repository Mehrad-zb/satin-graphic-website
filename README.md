# Satin New Website — service expansion
Updated October 4, 2026. Uses exactly the self-hosted Vazirmatn font and system fallback stack found in https://admin.satingraphic.ca/style-v08.css, for Latin and Persian text. New uploaded video is scroll controlled, with an updated poster and no audio.

Auto Detailing includes interior, exterior, paint correction and ceramic coating pages; online appointment requests and configurable service quote requests persist in D1. Plans are quoted individually. Appointment dates and times are preferred requests in America/Toronto; staff must confirm scope, pricing and availability. The application does not yet send automatic email/SMS or integrate a calendar. No public API exposes customer records. Records can be inspected by the site owner using the Sites database tools.

Social Media Services and Videography follow the same page structure and persist configured quote requests. Existing unrelated forms remain preview demonstrations. Design Studio connects to the separately hosted T-shirt Studio; customer access to that studio was authorized to be public.

Ten manually observed real Google reviews rotate randomly, three visible at a time on desktop and all three stacked on mobile. Three short original excerpts and seven clearly labelled editorial summaries are linked to Google. The associated review photos are loaded from the original observed Google image URLs. Rating snapshot: 5.0 / 204, October 4, 2026. These are not live API data.

Original official TeckWrap, KPMF and HEXIS logos added. Arlon uses its original mark with a black resting state. New service illustrations were generated by ImageGen and labelled as illustrative, not actual client work.

SEO: prerendered public service pages, titles/descriptions, canonical URLs pointing to this publication, LocalBusiness / Service / Breadcrumb markup, and sitemap. English completed pages are indexable; incomplete translation drafts and account routes stay noindex. Search rankings are not measured or guaranteed. No self-serving Google star rating schema is added.

Source output is dist/client plus dist/server. .openai/hosting.json declares D1 as DB. Schema is db/schema.ts; Drizzle migration is drizzle/0000_slim_eternity.sql. No real availability schedule or service prices have been provided yet.
